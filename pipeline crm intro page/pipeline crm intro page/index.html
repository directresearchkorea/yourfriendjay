안정성과 확장성을 극대화한 3-Layer Architecture

L1

Directive Layer

SOP 표준 운영 절차를 마크다운 형태의 평문으로 정의합니다. 비즈니스 로직과 요구 사항을 규정하여 AI 에이전트가 완벽하게 준수할 수 있도록 유도합니다.

L2

Orchestration Layer

시스템에 배정된 AI Agent가 설정된 Directives를 해독하고 최적의 워크플로우를 실시간으로 결정 및 분기 처리하여 강력한 의사결정을 수행합니다.

L3

Execution Layer

AI의 결정을 바탕으로 실제 작동하는 개별 Python 스크립트 모음입니다. API 연동, DB 트랜잭션, 메일 송수신 등 결정론적이고 견고한 작업 처리를 담당합니다.

실시간 RFQ 연락처 시트

시스템에 자동 등록된 수많은 비즈니스 연락처와 RFQ 상세 정보를 한눈에 관리할 수 있는 데이터 시트입니다. 의뢰 회사, 담당자 연락처, 진행 상태(Status), 동의 여부(VIP Newsletter) 등 핵심 정보의 수정과 조회가 즉시 반영됩니다.

영업 파이프라인 대시보드

비즈니스 동향을 실시간으로 직관화하는 메인 대시보드입니다. 전체 견적 요청(RFQ) 현황, 비딩(Bid) 제안 금액, 수주성공률(Win Rate) 및 최종 Win/Lost 데이터를 그래픽 대시보드를 통해 가시적으로 보여주어 의사결정을 가속화합니다.

소개 웹페이지 및 시스템 구조

반응형 웹 기술을 적용하여 제작된 시스템 소개 랜딩 페이지입니다. PC와 모바일 기기 어느 환경에서나 유려하게 표시되며, 복잡한 인텔리전스 백엔드 아키텍처와 시작 가이드를 사용자 및 운영자에게 정밀하고 고급스럽게 전달합니다.
