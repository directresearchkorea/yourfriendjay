데이터 수집 파이프라인 (Data Fetcher)

구글 캘린더 API를 통해 당일 일정을 파싱하고, SMTP/IMAP 프로토콜로 이메일을 수집하며, 로컬 윈도우 환경에 최적화된 GUI 자동화 트리거를 활용해 카카오톡 대화 로그를 실시간 비정형 텍스트 상태로 수집해 옵니다.

# src/email_fetcher.py def fetch_emails(user, password, target_date): mail = imaplib.IMAP4_SSL("imap.gmail.com") mail.login(user, password) # ... 날짜 검색 및 이메일 텍스트 구조화 파싱 진행 return parsed_emails

다중 채널 데이터 수집 (Fetcher)

이메일 수신함, 구글 캘린더 일정 목록, 로컬 메신저 클라이언트를 주기적으로 모니터링하여 원시 데이터를 정규 패턴 텍스트 형태로 안전하게 추출합니다.

from src.chat_reader import read_and_archive_chat_logs # 메신저 창을 검색하고 대화 로그를 로컬 버퍼로 백업 chat_logs = read_and_archive_chat_logs()
🧠

AI 기반 업무 통합 분석 (Analyzer)

Gemini AI의 고성능 자연어 이해 성능을 이용하여, 하루 동안의 다차원 업무 데이터를 유기적으로 맥락 분석하고 가독성 높은 리포트를 생성합니다.

# Structured JSON Output 프롬프트 결합 report_text = analyze_all_data( emails, chat_logs, calendar_events, previous_report )
💾

구조화 DB 영구 적재 (DB Engine)

AI 분석 결과물에서 정형 JSON 블록 데이터를 자동 분리 및 파싱하여, 추후 대시보드나 검색 시스템에 활용할 수 있도록 관계형 DB(SQLite)에 저장합니다.

# DB 모델 스키마에 자동 맵핑 저장 save_all_projects_to_db(report_date_str, json_data)

일일 메일 자동 배포 (Sender)

분석이 완료되는 즉시, 마크다운으로 깔끔하게 포맷팅된 리포트 파일을 이메일 템플릿으로 래핑하여 지정된 수신인들에게 즉시 SMTP 전송합니다.
